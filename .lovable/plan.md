

# منصة DOMA — خطة التنفيذ

## الرؤية العامة
منصة مغلقة لإدارة العقود والمشاريع العقارية في المملكة العربية السعودية، مع خريطة تفاعلية ومؤشرات حرارية، و5 مستويات اشتراك، وتواصل ذكي داخلي.

---

## المرحلة 1 — الأساس والواجهة العامة

### 1.1 الهوية البصرية والتصميم
- نظام ألوان قوي تسويقياً ومريح للعين
- خطوط رسمية بدون Bold نهائياً في كامل المنصة
- أيقونات Minimal بدون خلفيات أو تظليل
- دعم ثنائي اللغة (عربي RTL / إنجليزي LTR) مع زر تبديل اللغة

### 1.2 الصفحة الرئيسية العامة (قبل التسجيل)
- تعريف منصة DOMA مع صور عينات للداشبورد
- معرض شعارات القطاعات والجهات مع تنبيه قانوني (لا تعني شراكة)
- صفحة الاشتراكات الخمسة (أفراد، شركات وساطة، شركات براندات، إدارة عقود/مشاريع، بنوك)
- روابط: الشروط والأحكام، سياسة الاستخدام، سياسة الخصوصية
- الفوتر: DOMA v1.0.0 — شركة دوما للتقنية

### 1.3 التسجيل وتسجيل الدخول
- تسجيل بالبريد الإلكتروني مع تفعيل
- موافقة على الشروط والسياسات مع حفظ سجل الموافقة (Timestamp + Version)
- اختيار نوع الاشتراك عند التسجيل

### 1.4 قاعدة البيانات — الجداول الأساسية
- جدول المستخدمين والأدوار (5 أنواع اشتراك)
- جدول المشاريع (Projects): الاسم، المدينة، الحي، الشارع، الإحداثيات، الحالة، التواريخ
- جدول الوحدات (Units): النوع، المساحة، الحالة، السعر
- جدول العقود (Leases): تواريخ البداية والنهاية، المدة (تلقائية)، الحالة
- سياسات أمان (RLS) حسب الدور

## المرحلة 2 — إدارة المشاريع والوحدات والعقود

### 2.1 إدارة المشاريع
- إضافة مشروع جديد (تحت الإنشاء / جاهز)
- تحديد عدد الوحدات حسب النوع (معارض، محلات، مكاتب، شقق)
- تاريخ البدء والانتهاء المتوقع

### 2.2 إدارة الوحدات
- تسجيل تفاصيل كل وحدة (نوع، مساحة م²)
- حالة الإشغال تُحسب تلقائياً من العقد المرتبط
- سعر العرض للشواغر مع المدة والعمولة

### 2.3 إدارة العقود
- إنشاء عقد مرتبط بوحدة
- تاريخ البداية والنهاية ومدة العقد (تلقائية)
- حالة العقد (نشط، منتهي، قريب الانتهاء)
- ربط رقم عقد إيجار (اختياري)

### 2.4 نموذج عرض السعر (PDF)
- نموذج رسمي للوحدات الشاغرة
- يتضمن: بيانات المشروع، الوحدة، المساحة، السعر، المدة، العمولة، ضريبة التصرفات
- إخراج PDF قابل للطباعة بتصميم رسمي
- رقم إصدار النموذج ورقم العرض + شعار DOMA

## المرحلة 3 — الخريطة والداشبورد

### 3.1 خريطة المملكة التفاعلية
- الصفحة الرئيسية بعد الدخول = خريطة المملكة
- اختيار مدينة → عرض المشاريع والمؤشرات
- اختيار حي → قائمة مشاريع + نسبة إشغال + مساحات شاغرة
- اختيار شارع → تفاصيل الوحدات المتاحة
- فلاتر: نوع الوحدة، الحالة، المساحة (من/إلى)

### 3.2 مؤشرات حرارية (Heatmap)
- طبقة مشاريع تحت الإنشاء
- طبقة الشواغر الحالية
- طبقة الطلب (طلبات الاستئجار)

### 3.3 لوحة التحكم (Dashboard Snapshot)
- عرض سريع: نسبة الإشغال، الشواغر، عقود قريبة الانتهاء
- طلبات جديدة، مشاريع تحت الإنشاء
- تحميل كسول (Lazy) للتفاصيل عند فتح التبويب
- محتوى مخصص حسب دور المستخدم

## المرحلة 4 — طبقة الطلب والتواصل الذكي

### 4.1 طلبات الاستئجار (Demand Requests)
- إنشاء طلب: نوع (مكتب/محل/معرض/شقة)، مدينة/حي، مساحة، ميزانية، مدة
- عرض الطلبات على الخريطة كطبقة طلب

### 4.2 ملفات الشركات والبراندات
- ملف شركة (Company Profile): الاسم، القطاع، متطلبات التوسع، نطاق المدن
- تحديد احتياجات التوسع واستقبال عروض المساحات

### 4.3 التواصل الذكي الداخلي
- سجل جهات (Brand/Company Registry) يُدار من الإدارة
- اقتراح جهات مناسبة عند توفر مساحة (حسب القطاع والمساحة والمدينة)
- إرسال "رسالة اهتمام" من داخل النظام مع سجل تدقيق (Audit Log)
- إشعارات داخلية + بريد إشعاري اختياري
